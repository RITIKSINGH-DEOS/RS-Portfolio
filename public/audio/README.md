# Background Music / Audio Folder

This folder contains the background music used by the Contact Card (`2AM LO-FI` pill) in the portfolio.

### How to use your own music:
1. Copy your audio file (e.g., `.mp3`) into this folder (`public/audio/`).
2. Rename it to `lofi-ambient.mp3` to replace the default track, OR update the filename in `src/components/contact-card.tsx` (`AUDIO_SRC`).
